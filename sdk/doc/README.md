# Trezor Modular App SDK Documentation

> **⚠️ Work in progress:** The modular app SDK is under active development. Everything documented here — APIs, workflows, examples, tooling — can and will change at any time without notice.

- [Development](development.md) — how to build a modular app: `Cargo.toml` metadata, project structure, and a walkthrough using the `trezor-modular-app` example.
- [Logging](logging.md) — log macros (`debug!`, `info!`, `warn!`, `error!`) available to modular apps and how to use them.
- [Testing](testing.md) — building firmware with extapp support, running the emulator, and loading an app for testing.
